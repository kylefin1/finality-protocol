# Coordinated vulnerability disclosure

Report vulnerabilities through a private GitHub security advisory for this
repository when available. Do not place exploitable details, protected data,
credentials, or third-party secrets in a public issue.

Include the exact release, artifact hash, minimal reproduction, impact, and any
known mitigations. Finality will acknowledge receipt, preserve the report, and
classify it as confirmed, not confirmed, duplicate, or disputed with reasons.

This is a disclosure process, not a funded bug bounty. No reward, employment,
customer relationship, or endorsement is promised. Safe-harbor terms require
separate legal approval and are not implied here.
