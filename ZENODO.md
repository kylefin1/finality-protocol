# Immutable deposit process

1. Resolve `LICENSE-REVIEW.md` and replace repository placeholders in
   `CITATION.cff`.
2. Create a signed GitHub release for an exact repository commit.
3. Connect the repository to Zenodo and enable release archiving.
4. Publish the GitHub release; record the generated version DOI and concept DOI.
5. Add the version DOI to the external report and its evidence submission.
6. Verify the deposited archive hash against the GitHub release artifact.

A DOI identifies an immutable deposit. It does not make its authors independent
or establish that the protocol is correct.
