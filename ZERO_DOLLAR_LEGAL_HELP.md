# Zero-dollar IP/legal help routes

These resources can reduce or eliminate legal fees, but acceptance is not guaranteed and each program applies its own eligibility rules.

## USPTO Patent Pro Bono Program

Official page: https://www.uspto.gov/patents/basics/using-legal-services/pro-bono/patent-pro-bono-program

The USPTO describes a nationwide network that matches qualifying financially under-resourced inventors and small businesses with volunteer patent attorneys/agents. General USPTO contact listed by the program: probono@uspto.gov.

### Intake message

Subject: Pro bono patent/publication review for an interoperable distributed-systems protocol

I am the founder of Finality Group and have developed Finality Reality Protocol (FRP) and a deterministic semantic kernel (FSK). I want to publish a frozen specification, conformance vectors, verification tooling and adversarial challenge material so outside parties can independently implement and falsify the protocol, while preserving proprietary implementation layers and any patent/trade-secret rights that should remain protected.

Some technical material has already been publicly disclosed. I need help identifying the earliest relevant disclosure dates, any filing deadlines, which mechanisms should be evaluated for patent protection before further publication, and an appropriate split licensing/patent posture for the normative specification, reference software and documentation.

I am seeking pro bono assistance and can provide a concise disclosure chronology, architecture summary, frozen artifact manifest and proposed public/private boundary.

## USPTO Law School Clinic Certification Program

Official page: https://www.uspto.gov/learning-and-resources/ip-policy/public-information-about-practitioners/law-school-clinic-1

The USPTO lists 70+ participating law-school clinics, including some that accept clients from anywhere in the United States. Acceptance is discretionary. Use the official list to contact a currently participating patent clinic.
