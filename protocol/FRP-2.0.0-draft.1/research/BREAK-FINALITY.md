# Break Finality

Objective: produce `FINAL` when a mandatory predicate is false or a mandatory
contradiction is present under the declared reference assumptions.

Attempt contract substitution, evidence mutation, source omission, correlated
quorum inflation, stale signature replay, out-of-order evidence, clock skew,
REOPEN corruption, certificate substitution, parser differentials, and STOP
bypass. Preserve the frozen release and provide exact inputs, commands,
expected/observed outputs, environment, and hashes.

Successful and unsuccessful attempts remain attributable to their authors. A
seller rerun is not an independent attack. This release has zero signed outside
attempts recorded.
