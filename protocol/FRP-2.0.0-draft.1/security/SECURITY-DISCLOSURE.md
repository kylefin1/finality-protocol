# Coordinated security disclosure

Report a suspected vulnerability or semantic discrepancy privately to
`security@finalitygroup.com` with the affected release, artifact hashes,
reproduction steps, expected/observed classification, and impact. Do not include
protected personal or customer data. Finality should acknowledge, preserve the
report immutably, assign severity, reproduce, and publish a version-bound
advisory when appropriate.

No funded bounty is represented. The public “Break Finality” work is a technical
challenge and disclosure path, not a reward promise.
